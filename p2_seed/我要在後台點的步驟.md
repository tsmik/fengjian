# 你要進 Firebase 後台用滑鼠點的步驟（白話版）

> Claude Code 已經幫你做完：建好兩個專案、抓好設定值、填進程式。
> **剩下這份清單裡的事只能你親自點**（網頁後台的開關，程式碰不到）。
> 有兩個專案，每件事都要做兩次（一次 `rbf2app` 正式、一次 `rbf2app-staging` 測試）。
> 用你的 Google 帳號（chaojentseng@gmail.com）登入後台。卡住就截圖問我。

---

## 第 1 件：打開「用 Google 登入」

### 正式站 rbf2app
1. 網址列貼上、進去：
   `https://console.firebase.google.com/project/rbf2app/authentication`
2. 看到一個藍色按鈕 **「Get started」（開始使用）** → 點它。
3. 出現一排登入方式清單 → 找到 **「Google」** → 點進去。
4. 右上角有個開關 **「Enable」（啟用）** → 打開（變成藍色/綠色）。
5. 下面會要你選一個 **「Project support email」（支援用 email）** → 下拉選你的 email。
6. 點 **「Save」（儲存）**。
7. ✅ **成功的樣子**：回到清單，Google 那一列右邊顯示 **「Enabled」（已啟用）**。

### 測試站 rbf2app-staging
同上，把網址換成：
`https://console.firebase.google.com/project/rbf2app-staging/authentication`
（一樣 Get started → Google → Enable → 選 email → Save → 看到 Enabled）

---

## 第 2 件：加「授權網域」（讓我們的網站可以登入）

### 正式站 rbf2app
1. 進去：
   `https://console.firebase.google.com/project/rbf2app/authentication/settings`
2. 找到分頁/區塊 **「Authorized domains」（授權網域）**。
3. 點 **「Add domain」（新增網域）**，輸入：
   `rbf2app.pages.dev`
   → 按 Add。
4. ✅ **成功的樣子**：清單裡多出 `rbf2app.pages.dev`一列。
   （清單裡本來就有 `localhost` 跟 `rbf2app.firebaseapp.com`，那是正常的，別刪。）

### 測試站 rbf2app-staging
1. 進去：
   `https://console.firebase.google.com/project/rbf2app-staging/authentication/settings`
2. 同樣 Authorized domains → Add domain，這次輸入：
   `rbf2app-staging.pages.dev`
3. ✅ 清單多出 `rbf2app-staging.pages.dev` 一列。

---

## 第 3 件：建立資料庫（Firestore）

### 正式站 rbf2app
1. 進去：
   `https://console.firebase.google.com/project/rbf2app/firestore`
2. 點 **「Create database」（建立資料庫）**。
3. 地區（location）選 **`asia-east1`**（台灣/亞洲，較快）→ Next。
4. 模式問 Production / Test → 選 **「Production mode」（正式模式）** → Enable / Create。
5. ✅ **成功的樣子**：看到一個空的資料表畫面（沒有資料是正常的）。

### 測試站 rbf2app-staging
同上，網址換成：
`https://console.firebase.google.com/project/rbf2app-staging/firestore`
（一樣 Create database → asia-east1 → Production mode → 看到空資料表）
